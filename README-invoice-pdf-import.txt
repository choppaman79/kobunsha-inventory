対応する納品書
添付いただいた弘文社の横向き納品書と同じ配置のPDFに対応します。
文字データのあるPDFは文字を抽出し、スキャン画像は日本語・数字をOCRで読み取ります。
1回の読み取りは1ページです。複数ページのPDFは、ページ番号を指定して1ページずつ確認してください。
同じ納品書が複数ページに続く場合は、1つの確認画面へ残りの商品明細を手動追加して、1件の伝票として保存してください。同じ年・伝票番号を別々の伝票へ二重登録することはできません。
20MB以下のPDFを使用してください。配置や向きが異なるPDFでは、読み取り結果を手動で修正してください。
PDF本体は外部サービスへアップロードせず、ブラウザ内で読み取ります。読込用のプログラム・日本語データをインターネットから取得するため、通信が必要です。初回は時間がかかります。

操作
1. 「伝票・検品」→「納品書PDFから出荷伝票を作成（自動読取・確認修正）」を開きます。
2. PDFとページ番号を選び「PDFを読み取る」を押します。
3. 表示された原本と、読み取った次の項目を照合・修正してください。
   ・納品書の伝票番号
   ・取引区分コード（050など3桁）と区分名
   ・受注№
   ・出荷先コードと出荷先名
   ・取扱先コードと取扱先名
   ・計上日、倉庫
   ・商品コード、商品名、数量、単価
   住所・電話番号は任意です。右側に印刷された弘文社の住所・電話を、取扱先の住所・電話として取り込むことはありません。
4. 明細が不足していれば「明細を追加」、余分な行があれば「削除」を使って修正します。
5. 「修正内容を商品マスタと照合」を押します。
   商品コードが一致した登録商品の正式名称で、登録予定の内容を表示します。
   未登録・重複した商品コードは保存を止めます。勝手に新しい商品や在庫は作りません。
   添付例の5293などが在庫の商品マスタにない場合も、そのままでは登録できません。対象を確認して商品マスタを登録するか、適切な登録済みコードへ修正してください。
6. 登録予定内容を原本と照合し、確認チェックを入れて「確認した内容で出荷伝票を作成」を押します。
7. 作成された未検品伝票を開き「出荷指示書・検品JAN」を押すと、上部に伝票番号・取引区分・受注№・出荷先・取扱先を表示します。

表示と保存
・呼称は「取扱先」に統一しました。出荷先と取扱先は別項目です。
・050、03411などの先頭の0を含む番号は文字列として保存します。読取で0が欠けていないか、必ず確認してください。
・納品書の伝票番号と、アプリが採番する管理番号を別々に保存します。出荷指示書には両方表示します。
・同じ年・納品書の伝票番号での二重登録を防止します。コピーPDFや同時操作でも同じ番号を重複登録しません。
・取込だけでは在庫を減らしません。従来どおり、現品と個数別検品JANを照合して完了した時に反映します。
・出荷先台帳は自動で上書きしません。読み取って確認した出荷先・取扱先の内容を、この伝票に保存します。
・手作成の出荷伝票にも、納品書の伝票番号、取扱先コード、取引区分名の入力欄を追加しました。
・S1 Excel取込の依頼番号は、受注№と混同せず「依頼番号」として出荷指示書に表示します。
・商品用23×23mmシール、検品用62×29mmシール、S1 Excel取込、個数別検品JANの使用済み判定は維持しています。

読取に関する注意
黒い太枠・薄い印字・傾きで誤読することがあります。自動で確定せず、確認・修正後に保存する方式です。
読込エラーの場合は通信を確認して再実行してください。パスワード付きPDFは、パスワードなしで出力し直したPDFを使用してください。
番号・コード・商品と数量は原本と照合してください。1出荷伝票の検品上限は300個です。

検証
添付PDFの画像を使ったローカルOCRテストで、伝票番号319159、取引区分050、受注番号4548、出荷先コード32312、取扱先コード03411と、明細の商品コード・数量・単価を確認しました。
日本語の自動読み取り結果には誤読があり得るため、商品名は登録マスタとの照合結果も確認する仕組みです。
ブラウザ用の読み取りライブラリは指定バージョンの配信先へ到達できることを確認しました。ブラウザ内の全処理はライブラリを模したテストで、選択→読み取り結果→修正→確認チェック→保存まで確認しました。
テスト用データで、二重・同時取込の拒否、番号の先頭0の保持、未登録商品の停止、商品変更時の再確認、在庫・履歴が変わらないこと、出荷指示書の5項目の表示を確認しました。
既存のExcel取込、検品JAN、商品ラベル、JAN変更と全画面初期化の回帰テストも通っています。
実際のユーザー環境のブラウザ、Firebaseへの登録、プリンター・スキャナーでの実機検証は行っていません。まず少量で確認してください。
