操作例（翡翠5個）
1. 「伝票・検品」で出荷伝票を作成し、商品と数量5を登録します。
2. 伝票を開き「出荷指示書・検品JAN」を押します。初回に別々の検品番号を5個保存して、A4の出荷指示書に「1/5～5/5」の5つのバーコードを載せます。
3. A4プリンター・用紙A4・倍率100％で指示書を印刷します。
4. 接続済みのTera HW0010で、現品の商品JAN→指示書の対応する検品JANの順に読み取ります。2回で1個です。次の現品を取り、次の未使用番号で同じ操作を繰り返します。番号→現品の順でも照合できます。
5. 確認数が0/5→1/5→2/5→…→5/5と増え、読み取りごとに自動保存されます。5個すべてを確認して「検品完了として記録する」を押すと、在庫へ反映します。

運用上の仕様
・商品用JANは商品共通、検品用JANは伝票・商品明細・1個ごとに異なる専用番号です。「検品専用・販売不可」と表示し、POSの商品番号には使用しません。
・検品番号だけの読み取りでは数量は増えません。毎回、現品の商品JANとの照合が必要です。
・同じ検品番号の二重読み取り、別の伝票の番号、現品と異なる商品の番号を拒否します。
・画面を閉じる／再読み込み／同時に別端末から読む場合も、サーバー上の使用済み記録を確認します。
・再印刷では新しい番号を発行せず、同じ番号を印刷します。使用済みの番号は再印刷しても復活しません。
・検品中の確認数は読み取り専用で、検品済みチェックも自動です。未検品が残っている状態で出荷完了できません。
・読み取り中は通信が必要です。保存エラー時は数量を増やさず、通信を確認してから再読み取りしてください。状態が不明なときは伝票を開き直して確認数を確認します。
・A4指示書のほか、「専用検品シールを印刷」から62×29mmの数量分の検品JANシールも印刷できます。同じ番号なので、指示書とシールの両方を読んでも二重には増えません。プリンターロールも62×29mmに合わせます。
・1伝票につき最大300個です。それを超える場合は伝票を分けてください。
・未完了の既存出荷伝票で確認数が0なら、新方式の検品番号を発行できます。確認済み数量が保存されている旧伝票は自動でリセットしません。内容を確認して新しい出荷伝票を作成してください。
・過去の完了済み伝票・商品マスタ・在庫数は、ファイル更新や指示書印刷だけでは変更しません。
・入荷伝票の既存QR検品は従来どおりです。新方式の出荷検品は、更新したJAN版で行ってください。
・カメラ読み取りは出荷のJAN検品には対応していません。接続済みスキャナーを使用してください。
