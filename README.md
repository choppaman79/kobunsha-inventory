# 弘文社 在庫管理アプリ（Phase1）

商品マスタ登録 + 在庫一覧・増減 ができるところまでのMVPです。
予定管理・引き継ぎアプリと同じFirebaseプロジェクトを使い回す前提で作っています。

## できること（Phase1）
- 商品登録（商品名・分類・単位・現在庫数・在庫僅少ライン・備考）
- 在庫一覧表示（分類での絞り込み／商品名検索）
- 在庫数の＋／－ワンタップ増減（リアルタイム反映）
- 在庫僅少の商品を赤枠で強調表示
- 商品の編集・削除
- メンバー個別ログイン（予定管理アプリと同じ `名前@koubunsha.com` 形式）

## セットアップ

1. `firebase-config.js` を開き、`firebaseConfig` の中身を **予定管理アプリと同じ値** に書き換える
   （Firebaseコンソール → プロジェクトの設定 → 全般 → マイアプリ）
2. Firestoreのセキュリティルールに、このアプリ用のコレクション `inventory_products` への
   読み書き許可を追加する（ログイン済みユーザーのみ許可する例）
   ```
   match /inventory_products/{docId} {
     allow read, write: if request.auth != null;
   }
   ```
3. GitHubリポジトリを新規作成し、このフォルダの中身をpush
4. GitHub Pagesを有効化（Settings → Pages → mainブランチ）
5. メンバーのログインアカウント（`名前@koubunsha.com`）は予定管理アプリで
   すでに作成済みのものをそのまま使えます。新規メンバー分だけ追加してください。

## 商品データの登録について
200点を1件ずつ手入力するのは大変なので、Excelから一括登録するスクリプトも
別途用意できます（商品リストをCSVでいただければ対応可能）。
